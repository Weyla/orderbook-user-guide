# Fogalomtár

| Fogalom | Jelentés |
|---------|----------|
| **Rendelés** | Egy ügyfél egy kiszállítása vagy átvétele: tételek, szállítás, időpont, számlák. |
| **Jegyzet (naptárban)** | Rendelés helyett felvett szürke naptári bejegyzés tételek nélkül (pl. „Szerviz 10–12”). Nem foglal szállítási időt. |
| **Napi jegyzet** | Egy naphoz tartozó szöveg, a naptár oszlopának fejlécében látszik (📋). |
| **Nap tele** | Megjelölés, hogy az adott napra már nem fér több kiszállítás. A szabad időpont kereső kihagyja ezt a napot. |
| **Vágási limit** | Egy napra vágható tűzifa maximális mennyisége (m3). Napi felülírással módosítható. |
| **m3** | Köbméter, a tűzifa mennyiségi egysége. |
| **Tűzifa termék** | Olyan termék, amelyet vágni kell. A Vágás oldalon kék címkével jelenik meg. |
| **Alapanyag** | Amiből a termék készül (pl. rönk). A **Készre jelölés** és a gyártás vonja le. |
| **Termék / Változat (variáció)** | Egy termék több változatban létezhet (pl. hossz, kiszerelés). Az ár változatonként eltérhet. |
| **Fő készlet** | Az alapértelmezett, saját raktár. |
| **Külső hely** | Másik raktárhely (pl. külső telephely). Csak külső gyártás és mozgatás használja. |
| **Nyitott rendelések után** | A Készlet oldalon: mennyi marad, ha a még ki nem szállított rendelések elviszik a magukét. |
| **Beszerzési bizonylat** | Egy beérkezett szállítmány rögzítése (beszállító, tételek, költségek, csatolt számla). |
| **Gyors hozzáadás** | Beszerzés gyors rögzítése csak tételekkel. A részleteket (beszállító, költség) később kell pótolni. |
| **Dokumentum-sor** | Beszkennelt beszerzési papírok várólistája, amíg valaki egy beszerzéshez nem csatolja. |
| **Eladás** | Közvetlen raktári eladás rendelés nélkül (pl. az udvaron vitték el). |
| **Előleg rendelés** | Olyan eladás, amelyre előlegszámla készül, és a készletet csak a befejezéskor vonja le. |
| **Számla** | Normál számla a Számlázz.hu-n keresztül. |
| **Előlegszámla** | Előre fizetett összegről szóló számla. Utána **végszámla** zárja le. |
| **Végszámla** | Az előlegszámla utáni elszámoló számla; mindig átutalásos. |
| **Sztornó** | Egy kiállított számla érvénytelenítése egy új, ellentétes számlával. Nem törlés. |
| **E-számla / Papír** | E-számla: elektronikus számla e-mailben. Papír: nyomtatandó számla. |
| **Teljesítés dátuma** | A számlán szereplő teljesítési nap. |
| **Fizetési határidő** | Eddig kell kifizetni a számlát. |
| **Szállítólevél (Szállító)** | Hivatalos (pl. faanyag-kereskedelmi) szállítójegy, amelyet a külső Szállító rendszer állít ki. Sorszáma pl. `2026-ABC-0012` (a középső betűk a cég saját előtagja). |
| **Aláírt példány / aláírt jegy** | A szállítólevél ügyfél által aláírt, lefotózott vagy beszkennelt példánya. |
| **Fuvaros / Fuvarozó** | Aki a szállítást végzi. Az alapértelmezett fuvaros a saját autónk, a többi külső fuvaros. |
| **Ajánlott idősáv** | Az ügyfélnek megadható várható érkezési idősáv. A rendszer számolja az indulásból és a város távolságából. |
| **Első kiszállítás** | A nap legelső kiszállítása (reggel), amikor az indulás fix. |
| **Problémás ügyfél** | Megjelölés (‼️), hogy az ügyféllel korábban gond volt. Mindenhol figyelmeztetés jelenik meg. |
| **Vevő megjegyzés** | Az ügyfélhez tartozó, időrendi megjegyzések. A **Hasítónak** jelölésűt a vágók is látják. |
| **Megjegyzés a vágónak** | Rendeléshez tartozó megjegyzés, amelyet a vágók és a fuvarosok is látnak. |
| **Rendelés megjegyzés** | Belső megjegyzés a rendeléshez. A vágók és a külső fuvarosok nem látják. |
| **Bármely mező (joker)** | Keresőmező, amely az ügyfél és rendelései szinte minden adatában keres. |
| **Kuka** | A törölt rendelések helye. Csak az admin látja és állíthatja vissza. |
| **WP / Webshop rendelés** | A webshopból (WordPress/WooCommerce) automatikusan érkezett rendelés. |
| **EKAER szám** | Közúti áruszállítás bejelentési száma, ha kell. |
| **Leltár** | Tényleges készletszámlálás. Admin funkció. |
